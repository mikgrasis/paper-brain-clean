# Tags

The only tags reference notes may use. Hierarchical, lowercase, `/`-separated; a note tagged `tensors/cp` also counts toward `tensors`. Propose a new tag here before using it.

| Tag | Covers |
|---|---|
| `tensors` | tensor algebra, decompositions and their applications |
| `tensors/cp` | CP (CANDECOMP/PARAFAC) decomposition |
| `tensors/tucker` | Tucker decomposition and HOSVD |
